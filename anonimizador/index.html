Anonimizador de textos

Sustituye nombres por códigos y códigos por nombres en un texto, usando una tabla CSV de correspondencias. Sirve para anonimizar y para volver al texto original con el mismo CSV.

Tus datos no salen de este equipo Todo se procesa en tu navegador. Los archivos no se envían a ningún servidor, no se usan servicios externos y no se guardan: al cerrar o recargar la página desaparecen.

1. Tabla de correspondencias (.csv)

Columnas nombre y código, con encabezados. Separador coma o punto y coma.

Ningún archivo cargado.

2. Texto a transformar (.txt)

Puede contener nombres, códigos o ambos. Lo demás no se modifica.

Ningún archivo cargado.
