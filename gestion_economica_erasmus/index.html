Informe completo

Genera un archivo con el resumen presupuestario (presupuestado, gastado y disponible) y el historial completo de apuntes.

Los datos se guardan automáticamente en la base de datos local (IndexedDB) de este navegador cada vez que se añade, edita o elimina un apunte, y también al modificar los presupuestos. No se envía información a ningún servidor. Para conservar una copia de seguridad, usa las opciones de exportación.
